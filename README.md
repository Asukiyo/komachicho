# 小春町 / TYPE TOWN

和風の町を歩き、住民のWebサイトをつくりながらHTML・CSS・TypeScriptを学ぶブラウザゲームです。
Three.jsの町、Blender製の建物と人物、24段階の町の依頼、32課題の基礎教材を収録しています。

## GitHub Pagesへの配置

1. GitHubで `komachicho` リポジトリを作成します。GitHub FreeでPagesを使う場合はPublicにします。
2. このフォルダの**中身**をリポジトリの直下へ配置します。`package.json` と `docs/` が直下にある状態です。
3. **Settings → Pages → Build and deployment** を開き、Sourceを **Deploy from a branch**、Branchを **main**、Folderを **/docs** にしてSaveします。
4. Pagesのデプロイが完了すると、`https://asukiyo.github.io/komachicho/` で遊べます。リポジトリ名を変えた場合は、その名前がURLになります。

`docs/` はビルド済みです。初回の公開にNode.jsやターミナルでの操作は不要です。
`docs/`だけをリポジトリ直下に置く場合はPagesのFolderを`/(root)`にしますが、開発を続ける場合は上の構成を推奨します。
GitHub PagesのゲームとPublicリポジトリのソースは一般公開されます。個人の学習データは含めていません。

## 保存と移行

進捗・コード・納品ページは**現在のブラウザのlocalStorage**に保存されます。サーバーへの送信や端末間の自動同期はありません。
「学習データ」からバックアップJSONを書き出し、別のブラウザや端末で読み込めます。取り込み前に内容と置き換えを確認できます。
シークレットウィンドウ、サイトデータの削除、リポジトリ名や公開URLの変更に注意してください。書きかけも保存できるよう、制作室を閉じてからバックアップしてください。
対応する最新のChrome・Edge・Firefox・Safariで開いてください。Web Locksで複数タブの同時保存を直列化します。

旧chatgpt.site版のクラウド保存は自動移行されません。旧版は削除していません。
旧版の進捗JSONをすでに持っている場合は、そのまま「バックアップを選ぶ」で取り込めます。新しいゲームの初期データは空です。

## 開発

Node.js 24 LTSを推奨します。

```sh
npm ci
npm run dev
```

開発サーバーは127.0.0.1のみで待ち受けます。更新後は次を実行し、ソースと再生成された`docs/`を一緒にコミットします。

```sh
npm run build
npm test
npm run audit:security
```

`npm run build`はブラウザ内TypeScriptコンパイラーも再生成します。教材で使うTypeScriptは互換性確認済みの5.9.3を固定しています。
公開URLのサブディレクトリに対応した相対URLとハッシュルーティングを使用し、GitHub PagesにAPIサーバーは要求しません。

## セキュリティと検証

2026-10-29（日本時間）の移行時に、開発用を含む依存関係を監査しました。結果と変更の範囲は `SECURITY.md` を参照してください。
`package-lock.json`は再現可能なインストールのために含めています。今後の更新時も監査と教材テストを実行してください。
学習コードは隔離された実行領域で動きますが、端末全体の無制限な計算やメモリ消費まで防ぐ仕組みではありません。

公開用の`docs/`に個人のバックアップJSON・トークン・.envを入れないでください。バックアップはリポジトリ外で保管してください。

## 収録素材

町・人物・店内のGLBと編集用Blenderファイル、環境音を同梱しています。外部CDNや有料素材サービスへの接続は不要です。
`assets/blender/`が編集用素材、`public/models/`と`public/audio/`がゲーム用素材です。
依存ライブラリの著作権表示・ライセンスは各パッケージに従います。TypeScriptのライセンス表示は`public/engine/typescript-LICENSE.txt`に同梱しています。
